Code 
def count_iqr_outliers(df, columns):
    """
    Count outliers in specified columns using the IQR method.
    
    Parameters:
    df (pd.DataFrame): The DataFrame to process
    columns: List of column names to check for outliers
    
    Returns:
    Number of observations flagged as outliers for each column
    """
    for column in columns:
        # Calculate quartiles and interquartile range
        Q1 = df[column].quantile(0.25)
        Q3 = df[column].quantile(0.75)
        IQR = Q3 - Q1
        
        # Calculate outlier bounds
        lower_bound = Q1 - 1.5 * IQR
        upper_bound = Q3 + 1.5 * IQR
        
        # Count outliers
        n_outliers = ((df[column] < lower_bound) | (df[column] > upper_bound)).sum()
        
        # Print results
        print(f'Number of outliers in {column}: {n_outliers}')

# Apply outlier detection to numerical variables
count_iqr_outliers(data_clean, ['bill_length_mm', 'bill_depth_mm', 'flipper_length_mm', 'body_mass_g'])

  • Body Mass vs. Flipper Length: Penguins with larger flipper lengths tend to have higher body mass, potentially due to size and ecological niche

Important

This is a typical example where accounting for sample stratification is important. The linear relationship between body mass and flipper length is positive and consistent across species, hence the high correlation coefficient (0.87). However, we get a negative value (-0.23) for the correlation coefficient between bill length and bill depth because the linear relationship holds only within each species but not at the dataset level. When computing within-species correlation coefficients, we get positive (and quite high) values, as discussed in Section 8.

7. Random Sampling and Confidence Intervals

Sampling and Confidence Interval for Bill Length

Let’s take a random sample and calculate confidence intervals.

Code 
# Set sample size
n = 30

# Take a random sample with fixed seed for reproducibility
sample_data = data_clean.sample(n, random_state=42)

# Calculate sample and population means
sample_mean = sample_data["bill_length_mm"].mean()
population_mean = data_clean["bill_length_mm"].mean()

print(f"Sample mean bill length: {sample_mean:.2f}")
print(f"Population mean bill length: {population_mean:.2f}")
Sample mean bill length: 44.25
Population mean bill length: 43.99

Interpretation:

  • The sample mean bill length is close to the population mean, demonstrating that even small samples can be useful for estimating population parameters

Now let’s calculate a 95% confidence interval for the sample mean.

Code 
# Calculate standard deviation of the sample
sample_std = sample_data["bill_length_mm"].std()

# Calculate 95% confidence interval
ci_lower = sample_mean - 1.96 * sample_std / np.sqrt(n)
ci_upper = sample_mean + 1.96 * sample_std / np.sqrt(n)

print(f"95% Confidence Interval: [{ci_lower:.2f}, {ci_upper:.2f}]")
print(f"Population mean: {population_mean:.2f}")

# Check if population mean is within confidence interval
if ci_lower <= population_mean <= ci_upper:
    print("The population mean is contained within the confidence interval")
else:
    print("The population mean is NOT contained within the confidence interval")

Population mean: 43.99

Simulation: Confidence Intervals Over Many Samples

Let’s simulate the process 100 times to see how often the confidence intervals contain the population mean.

Code 
# Parameters for the simulation
num_samples = 100

# Initialize counter for intervals containing population mean
count_within_ci = 0

# Loop to generate samples and compute confidence intervals
for i in range(num_samples):
    # Generate random sample (no fixed seed for different samples)
    sample = data_clean['bill_length_mm'].sample(n, random_state=None)
    sample_mean = sample.mean()
    sample_std = sample.std()  # Sample standard deviation
    
    # Calculate confidence interval
    ci_lower = sample_mean - 1.96 * sample_std / np.sqrt(n)
    ci_upper = sample_mean + 1.96 * sample_std / np.sqrt(n)
    
    # Check if population mean falls within confidence interval
    if ci_lower <= population_mean <= ci_upper:
        count_within_ci += 1

# Output results
print(f'Population mean: {population_mean:.2f}')
print(f'Number of confidence intervals containing the population mean: {count_within_ci}')
print(f'Proportion of confidence intervals containing the population mean: {count_within_ci / num_samples:.2%}')
Population mean: 43.99
Number of confidence intervals containing the population mean: 97
Proportion of confidence intervals containing the population mean: 97.00%

Interpretation:

  • The population mean should fall within the confidence interval approximately 95% of the time
  • This demonstrates that confidence intervals have good coverage properties when properly constructed
Important

Remember that here the population mean is fixed and the confidence interval is random. In general, we don’t have access to the population mean, that’s why we need to ensure that confidence intervals have good properties (on average).

Confidence Intervals for Each Species

Following the approach of Section 7, let’s compute 90% confidence intervals for flipper length within each species.

Code 
# Calculate 90% confidence intervals for each species
for species in data_clean["species"].unique():
    species_data = data_clean[data_clean["species"] == species]
    mean_flipper = species_data["flipper_length_mm"].mean()
    std_flipper = species_data["flipper_length_mm"].std()
    n = len(species_data)
    
    # Calculate 90% confidence interval
    ci = stats.norm.interval(0.90, loc=mean_flipper, scale=std_flipper/np.sqrt(n))
    
    print(f"{species}: 90% CI for flipper length = ({ci[0]:.2f}, {ci[1]:.2f})")

Gentoo: 90% CI for flipper length = (216.24, 218.23)

Interpretation:

  • The confidence intervals for flipper length do not overlap between some species, suggesting significant species-level differences in this trait
  • These differences likely reflect different environmental adaptations

9. Summary and Further Questions

Summary of Findings

  • The Palmer Penguins dataset reveals distinct differences in body structure among penguin species, likely due to their different environments and behaviors
  • Distributions are near-normal for most variables, though body mass shows some skew, possibly indicating a larger spread in penguin sizes
  • Outliers in body mass and bill length highlight individual variations that could be due to age, health, or measurement
  • Confidence intervals reinforce that samples can reliably estimate population parameters, and distinct CIs across species suggest real differences in physical traits

Further Questions for Exploration

If extending this analysis, we could investigate: - Differences in body mass across years - Impact of sex on size differences - Comparisons of penguin measurements across different islands (a factor we completely left out in our analyses)
