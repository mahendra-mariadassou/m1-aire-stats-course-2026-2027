  1. Draw multiple (say 10 000) samples of varying sizes \(n\) (e.g., 10, 30, 100) from a known distribution (normal distribution with a mean of \(\mu = 50\) and standard deviation of \(\sigma = 10\)).

  2. Plot histograms of the sample means for each sample size.

  3. Show that as sample size increases, the distribution of the sample means becomes narrower

  4. Show that the standard deviation scales as the square root of the sample size

  5. Plot \(\sqrt{n}(\bar{x} - \mu)/\sigma\) instead of the sample mean \(\bar{x}\). How does the distribution change when \(n\) increase ?

Code 
# Parameters
population_mean = 50
population_std = 10

# Sample sizes
sample_sizes = [10, 30, 100]
max_size = max(sample_sizes)
num_samples = 10000

means = pd.DataFrame(index=range(num_samples), columns=['mean_10', 'mean_30', 'mean_100'])
# Sample 100 observations from a normal distribution, compute the mean based on the first 10 / 30 / 100 observations and store them
for i in range(num_samples):
  sample = np.random.normal(population_mean, population_std, max_size)
  means.loc[i] = [sample[:size].mean() for size in sample_sizes]

The distribution of \(\bar{x}\) becomes narrower…

Code 
# Plot histograms of unscaled sample means
for i, size in enumerate(sample_sizes):
    plt.figure()
    sns.histplot(means.iloc[:, i], bins = 20, stat="density", color = "skyblue")
    plt.xlim(35, 65)  # Par exemple, de 0 à 50
    
    ## Add theoretical gaussian density
    x = np.linspace(-35, 65, 100)
    y = norm.pdf(x, 50, population_std / np.sqrt(size))
    plt.plot(x, y, color="red", linewidth=2)
    
    plt.title(f'Sample Size = {size}')

…but not the one of \(\sqrt{n}(\bar{x} - \mu)/\sigma\)

Code 
# Plot histograms of rescaled sample means
for i, size in enumerate(sample_sizes):
    plt.figure()
    sns.histplot( np.sqrt(size) * (means.iloc[:, i] - population_mean) / population_std, bins = 20, stat = "density", color = "skyblue")
    plt.xlim(-5, 5)
    ## Add theoretical gaussian density
    x = np.linspace(-5, 5, 100)
    y = norm.pdf(x, 0, 1)
    plt.plot(x, y, color="red", linewidth=2)
    
    ## Add title
    plt.title(f'Sample Size = {size} (rescaled estimate)')

Note

Means of gaussian random variables are nice because, up to a \(\sqrt{n}\) rescaling , their distribution doesn’t depend on \(n\) anymore.

Confidence Intervals from Normal and Non-Normal Distributions

Objective: Explore how confidence intervals work with normal and non-normal distributions.

  • Normal
  • Bernoulli
  • Exercise
  • Solution
  • Draw a sample of size \(n = 10\) from a normal distributi\on with the same mean and standard devation as the above binomial and compute the 95% confidence interval for the mean using the formula

\[IC_{0.95} = \left[ \hat{\mu} \pm \frac{\hat{\sigma}}{\sqrt{n}} q_{0.975}\right]\]

where \(q_{0.975}\) is the quantile of order 97.5% of the student’s distribution (more on that in future lectures) that you can compute with q0975 = stats.t.ppf(0.975, df = n-1) and \(\hat{\mu}\) and \(\hat{\sigma}\) are the sample mean and sample standard deviation.

Note

If the variance was known, the confidence interval would be simpler as we would use the known value for \(\sigma\).
\[IC_{0.95} = \left[ \hat{\mu} \pm \frac{\sigma}{\sqrt{n}} q_{0.975}\right]\]

In that case, the distribution of the pivot statistic is also simpler as it’s simply a standard normal distribution \(\mathcal{N}(0, 1)\) , the quantiles of which you can access with stats.norm.ppf(0.975) . You can also compare both quantiles to see how estimating the variance impacts the width of the confidence interval.

  • How frequently does the population mean fall in the confidence interval ?
Code 
# Parameters
population_mean = 20
population_std = 4

# Sample size
n = 10
## length of confidence interval
q0975 = stats.t.ppf(0.975, df = n-1)

# Normal Distribution
normal_sample = np.random.normal(loc=population_mean, scale=population_std, size=n)
sample_mean = normal_sample.mean()
sample_std = normal_sample.std()
ci_normal = [sample_mean - q0975 * sample_std / np.sqrt(n), sample_mean + q0975 * sample_std / np.sqrt(n)]

# 
print(f"95% CI for Normal Sample Mean: {ci_normal}")
95% CI for Normal Sample Mean: [np.float64(16.538589386870964), np.float64(21.61538166723661)]
Code 
## Repeat 10 000 times and compute how often the CI covers the true parameter
num_samples = 10000

# Initialize a counter for how many times the population mean falls within the CI
count_within_ci = 0

# Loop to generate samples and compute confidence intervals
for _ in range(num_samples):
    sample = np.random.normal(loc=population_mean, scale=population_std, size=n)
    sample_mean = sample.mean()
    sample_std = sample.std()  # Sample standard deviation
    ci_lower = sample_mean - q0975 * sample_std / np.sqrt(n)
    ci_upper = sample_mean + q0975 * sample_std / np.sqrt(n)

    # Check if the population mean falls within the confidence interval
    if ci_lower <= population_mean <= ci_upper:
        count_within_ci += 1

# Output the results
print(f'Population mean: {population_mean:.2f}')
print(f'Number of confidence intervals containing the population mean: {count_within_ci}')
print(f'Proportion of confidence intervals containing the population mean: {count_within_ci / num_samples:.2%}')
Population mean: 20.00
Number of confidence intervals containing the population mean: 9419
Proportion of confidence intervals containing the population mean: 94.19%
